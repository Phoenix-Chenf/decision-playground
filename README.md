# 决策游乐场 · Decision Playground

**Phoenix Chen · Agile Coach**

关注敏捷协作、引导与决策练习。通过虚构情境，探索如何澄清上下文、比较备选、明确授权与协作边界。

公开版 v2.2：**60局、21类场景、7种规模**。支持单人推演、3人练习、团队与多团队共创，也提供较大规模的筹备材料。

## 开始使用

下载并解压完整发布包，直接用浏览器打开 `index.html`；基础功能可离线使用，无需安装、账号、服务器或付费模型。

- [快速选玩法](index.html#overview)：按场景、规模、时长、授权与参与形式选择。
- [60局游戏库](index.html#library)：虚构情境、角色、材料、选择、变化与复盘。
- [组织者会前筹备](index.html#organizer)：范围与授权、角色、拟议议程、材料与人工检查。
- [完整游戏手册](完整游戏手册.html)：全部60局，可阅读和打印。
- [玩法与规模方案](扩展玩法与规模方案.html)：连续战役、主持台、预置对话、组织输入与7种规模。
- [场景覆盖与选用](场景覆盖与选用.md)、[主持提示词](主持提示词/)：备课与自行选择的外部AI主持材料。

GitHub的文件预览不会运行互动页面。使用时下载完整包，再在本地打开；单独下载 `index.html` 也能运行核心互动，但周边手册链接需对应文件。

## 适用边界

组织者模式仅做会前筹备，不承担现场计时、正式决定或会后跟进。现有主持台保持独立。

单人支持自我推演和主持预演；3人总数包含引导师，支持固定1+2或三人轮换主持。主持轮换不转移业务授权，虚构回应不代替真实相关方同意。

所有人物、组织、数字、事件与回应均为虚构。预置对话不理解自由输入，不是实时模型。负责人取舍、参与者主动承接与引导师过程责任分别表达。

较大规模材料是设计建议，离线页面不提供多人实时协作。功能检查与模拟完成不证明真实学习、会议或组织成效，不用于人格排名、诊断或能力认证。

## 记录与分享

单局、扩展模式、组织输入、组织者筹备四类记录独立保存、分别导出JSON。公开简报排除模板私有上下文及非公开参与安排；完整筹备单与JSON仍保留这些安排，分享前自行核对。

公开版使用独立浏览器存储键，避免覆盖完整本地版记录。移动文件、换浏览器或换机器时，浏览器记录不保证自动继承，应分别导出与导入。

本版只接受其保留场景的记录。含其他场景的完整旧备份会被校验拒绝；请继续在完整本地版保存它们，不要删改唯一备份来迁移。

## 源码维护

成品已内嵌内容、样式、图标与程序。需要维护时编辑 `source/`，再构建；不要只修改生成HTML。

```sh
npm ci
npm run build
npm run check
npx playwright install chromium
npm run check:browser
npm run package
```

维护需Node.js 20或更新版本。浏览器检查使用隔离的虚构记录；`source/qa/` 是本机验证输出，不放入发布包。
